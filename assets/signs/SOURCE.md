# Hand-sign pictures: source and licence

These 13 pictures show the hand signs Jutsu Code recognises. They are cropped
from the photos in the README of the model's source project,
[Kazuhito00/NARUTO-HandSignDetection](https://github.com/Kazuhito00/NARUTO-HandSignDetection)
("Kind of hand-sign" table). They are the author's own webcam photos, not anime frames.

- Copyright (c) 2020 KazuhitoTakahashi
- Licence: MIT, the same licence as the model (see `model/LICENSE`).
- Note: the photos are README attachments, not files in that repository's tree.
  We take them to be covered by the MIT licence as "associated documentation files".
- Changes: we removed the red kanji label the demo draws (inpainting), cropped the
  photos to the hands, and resized them to 200x150.
- The Mizunoe photo is left out because the game doesn't use that sign.
